Dasar Komputer

Kenali hardware, software, perangkat input/output, penyimpanan dan cara merawat komputer.

Belajar masuk BIOS/UEFI, mengatur boot priority dan memahami proses boot komputer.

ROADMAP

Langkah belajar dari awal sampai bisa

01

Pahami dasar

Kenali komponen komputer, sistem operasi, file dan jaringan dasar.

02

Praktik BIOS & instalasi

Latihan boot menu, BIOS/UEFI, membuat installer dan memasang Windows dengan aman.

03

Bangun jaringan

Pasang RJ45, buat kabel straight/crossover, atur IP dan tes koneksi LAN.

04

Konfigurasi Mikrotik

Pelajari IP, DHCP, NAT, DNS, firewall dan pengujian koneksi internet.

05

Masuk Linux

Latihan terminal, perintah dasar, user, permission, paket dan jaringan.

06

Buat website

Belajar HTML dan CSS lalu membuat landing page dan mempublikasikannya di GitHub Pages.

07

Skill aplikasi

Latihan Word, Excel, PowerPoint, Figma dan WordPress untuk kebutuhan sekolah maupun kerja.
