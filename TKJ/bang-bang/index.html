02

Winbox, Interface & IP Address

Belajar masuk MikroTik menggunakan Winbox, mengatur interface WAN/LAN dan memberikan IP Address.

🖱️ Winbox

  1. Buka Winbox.
  2. Pilih perangkat MikroTik.
  3. Buka Interfaces.
  4. Ubah ether1 menjadi WAN.
  5. Ubah ether2 menjadi LAN.
  6. Buka IP → Addresses.
  7. Tambahkan 192.168.10.1/24 pada LAN.

💻 Terminal

/interface ethernet set ether1 name=WAN
/interface ethernet set ether2 name=LAN

/ip address add address=192.168.10.1/24 interface=LAN

/ip address print

03

WAN, Routing & DNS

Membuat MikroTik mendapatkan koneksi dari ISP, memahami default route dan melakukan pengujian DNS.

🖱️ Winbox

  1. IP → DHCP Client.
  2. Klik +.
  3. Pilih interface WAN.
  4. Apply → OK.
  5. Periksa IP yang diperoleh.

💻 Terminal

/ip dhcp-client add interface=WAN disabled=no

/ip dhcp-client print

/ip route print

/ip dns set servers=8.8.8.8,1.1.1.1

/ping 8.8.8.8
/ping google.com
Latihan: Bandingkan hasil ping 8.8.8.8 dengan google.com.

04

NAT & Internet Client

Belajar membuat komputer LAN menggunakan koneksi Internet melalui MikroTik. 

          INTERNET
              |
             WAN
              |
          [MIKROTIK]
              |
             LAN
              |
           SWITCH
          /  |  \
        PC1 PC2 PC3

🖱️ Winbox

IP → Firewall → NAT → + → Chain: srcnat → Out Interface: WAN → Action: masquerade.

💻 Terminal

/ip firewall nat add \
chain=srcnat \
out-interface=WAN \
action=masquerade

/ip firewall nat print

🧪 Tes Client

ping 192.168.10.1
ping 8.8.8.8
ping google.com
Soal: Apa fungsi NAT masquerade?

05

DHCP Server & Bridge

Membuat IP otomatis untuk client dan menggabungkan beberapa port MikroTik menjadi satu jaringan LAN.

💻 DHCP Terminal

/ip pool add name=pool-LAN \
ranges=192.168.10.10-192.168.10.254

/ip dhcp-server add name=dhcp-LAN \
interface=LAN \
address-pool=pool-LAN \
disabled=no

/ip dhcp-server network add \
address=192.168.10.0/24 \
gateway=192.168.10.1 \
dns-server=192.168.10.1

🌉 Bridge

/interface bridge add name=bridge-LAN

/interface bridge port add \
bridge=bridge-LAN interface=ether2

/interface bridge port add \
bridge=bridge-LAN interface=ether3

/interface bridge port add \
bridge=bridge-LAN interface=ether4

🧪 Tes Windows

ipconfig
ipconfig /release
ipconfig /renew
Latihan: Buat DHCP dengan range 192.168.10.10–192.168.10.254.

06

Firewall & VLAN

Pelajari keamanan dasar router dan pemisahan jaringan menggunakan VLAN.

🔥 Firewall

Chain utama:

  • Input — menuju router.
  • Forward — melewati router.
  • Output — berasal dari router.
/ip firewall filter print

🏷️ VLAN

             MIKROTIK
                |
              TRUNK
                |
             SWITCH
       ┌────────┼────────┐
       |        |        |
    VLAN 10  VLAN 20  VLAN 30
     ADMIN     GURU    SISWA

/interface vlan add \
name=vlan10 \
vlan-id=10 \
interface=bridge-LAN

/interface vlan add \
name=vlan20 \
vlan-id=20 \
interface=bridge-LAN

/ip address add \
address=192.168.10.1/24 \
interface=vlan10

/ip address add \
address=192.168.20.1/24 \
interface=vlan20
Soal: Apa perbedaan firewall input dan forward? Apa fungsi VLAN?

07

Routing, Hotspot & Bandwidth

Pelajari routing antarjaringan, Hotspot dan pembatasan bandwidth menggunakan Simple Queue.

🛣️ Static Route

/ip route add \
dst-address=192.168.20.0/24 \
gateway=192.168.10.2

/ip route print

📶 Hotspot

Hotspot dapat digunakan untuk jaringan sekolah, Wi-Fi publik, kafe dan lingkungan lainnya. 

/ip hotspot user add \
name=siswa \
password=12345

/ip hotspot user print

🚦 Bandwidth

/queue simple add \
name=PC1 \
target=192.168.10.10/32 \
max-limit=2M/2M
Latihan: Buat user Hotspot dan batasi satu client menjadi 2 Mbps.

Load Balancing, Failover & Monitoring

Pelajari penggunaan dua koneksi Internet, koneksi cadangan dan monitoring MikroTik. 

       ISP 1 ─────┐
                  |
              MIKROTIK ─── LAN
                  |
       ISP 2 ─────┘

⚖️ Load Balancing

  • PCC
  • ECMP
  • Connection Mark
  • Routing Mark
  • Mangle

🔄 Failover

/ip route add \
dst-address=0.0.0.0/0 \
gateway=ISP1 \
distance=1

/ip route add \
dst-address=0.0.0.0/0 \
gateway=ISP2 \
distance=2

📊 Monitoring

/tool torch ether1

/interface monitor-traffic ether1

/system resource print

/log print

Backup, Troubleshooting & Proyek Akhir

Modul terakhir menggabungkan seluruh materi menjadi proyek jaringan sekolah.

/export file=backup-config

/ip address print

/ip dhcp-server lease print

/ip route print
