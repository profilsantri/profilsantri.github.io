PROJECT JARINGAN SEKOLAH

📚 Kurikulum Lengkap 12 Level

Klik setiap level untuk memperluas materi, melihat topologi jaringan, serta menyalin command konfigurasi MikroTik siap pakai.

01
🟢 LEVEL 1 — DASAR MIKROTIK

Pengenalan MikroTik, Winbox, Topologi, & IP Address Pertama

Poin Pembelajaran:

  • Apa itu MikroTik & RouterOS
  • Fungsi router & MikroTik dalam jaringan
  • WAN, LAN, Internet, MAC Address, IP Address
  • Mengenal port ether1 (WAN), ether2 (LAN)
  • Akses via Winbox, WebFig, & Terminal

Topologi Lab Dasar:

             INTERNET
                 │
              ether1
           ┌──────────┐
           │ MikroTik │
           └──────────┘
              ether2
                 │
             SWITCH
          ┌──────┼──────┐
          │      │      │
         PC1    PC2    PC3

Command & Praktik Sesi 1:

1. Memberi Identitas / Nama Router:

/system identity set name=MikroTik-TKJ

2. Cek Interface / Port Ethernet:

/interface print

3. Memberikan IP Address ke ether2 (LAN):

/ip address add address=192.168.10.1/24 interface=ether2
02
🟡 LEVEL 2 — INTERNET

DHCP Client, DHCP Server, DNS, Default Route, & NAT Masquerade

Poin Pembelajaran:

  • DHCP Client dari modem/ISP ke ether1
  • DHCP Server untuk otomatis membagikan IP ke client (Pool, Lease, Gateway)
  • Pengaturan DNS Public (8.8.8.8, 1.1.1.1)
  • Default Route (0.0.0.0/0)
  • NAT (Network Address Translation) / Masquerade agar client bisa online

Konsep NAT:

[ PC Client ]
↓
[ MikroTik Router ]
↓
[ NAT (Masquerade) ]
↓
[ Internet ]

Command Utama:

1. DHCP Client ke Internet (ether1):

/ip dhcp-client add interface=ether1 disabled=no

2. Setting DNS Server:

/ip dns set servers=8.8.8.8,1.1.1.1 allow-remote-requests=yes

3. Firewall NAT Masquerade (Wajib agar internet jalan):

/ip firewall nat add chain=srcnat out-interface=ether1 action=masquerade
03
🟠 LEVEL 3 — ROUTING

Routing Dasar, Static Routing, & Inter-VLAN Routing

Poin Pembelajaran:

  • Connected Route & Static Route
  • Default Route & Routing Table
  • Menghubungkan dua Router berbeda segmen (Router A & B)
  • Inter-VLAN Routing (Admin, Guru, Siswa, Tamu)

Contoh Static Route:

Router A (192.168.10.1) 
       │ (Kabel / Gateway)
Router B (192.168.20.1)

Contoh Command Static Route:

/ip route add dst-address=192.168.20.0/24 gateway=192.168.10.254
04
🔴 LEVEL 4 — FIREWALL

Firewall Dasar (Input, Forward, Output), Filter Rules, & Blokir Situs

Poin Pembelajaran:

  • Memahami rantai firewall: input, forward, output
  • Aksi accept, drop, reject
  • Connection state (established, related, invalid)
  • Blokir IP, port tertentu, atau situs terlarang

Konsep Keamanan:

Firewall bertindak sebagai benteng pengaman antara jaringan luar (Internet) dengan jaringan lokal (LAN) sesuai aturan policy admin.

Contoh Blokir IP Address:

/ip firewall filter add chain=forward src-address=192.168.10.50 action=drop
05
🔵 LEVEL 5 — BANDWIDTH MANAGEMENT

Simple Queue, Queue Tree, & Mangle (Administrator Level)

Poin Pembelajaran:

Membatasi kecepatan upload & download client menggunakan Simple Queue, serta klasifikasi tingkat lanjut menggunakan Mangle dan Queue Tree.

Contoh Limit Simple Queue (PC 1 max 5Mbps):

/queue simple add name=Client-PC1 target=192.168.10.2 max-limit=5M/5M
06
🟣 LEVEL 6 — VLAN (Virtual Local Area Network)

VLAN Dasar, Tagged, Untagged, Access, Trunk, & Bridge VLAN Filtering

Poin Pembelajaran:

Memisahkan jaringan fisik menjadi beberapa segmen virtual (VLAN 10: Admin, VLAN 20: Guru, VLAN 30: Siswa) lewat satu kabel trunk.

Contoh Konfigurasi VLAN 10 pada Interface ether2:

/interface vlan add name=vlan10-admin vlan-id=10 interface=ether2
07
🟤 LEVEL 7 — HOTSPOT SERVER & VOUCHER

Membuat Halaman Login WiFi, User Profile, & Sistem Voucher Otomatis

Poin Pembelajaran:

Setup Hotspot server, kustomisasi halaman login, manajemen user profile, pembatasan durasi waktu (time limit), dan cetak voucher internet.

08
⚫ LEVEL 8 — WIRELESS & TROUBLESHOOTING

Konfigurasi Access Point, Station, Security WPA2/WPA3, & Analisis Sinyal

Poin Pembelajaran:

Pengaturan SSID, channel frequency, security profile, mengatasi WiFi lambat, sinyal lemah, dan gangguan interferensi kanal.

09
🟧 LEVEL 9 — VPN (Virtual Private Network)

WireGuard, OpenVPN, & Site-to-Site VPN Antar Kantor

Poin Pembelajaran:

Menghubungkan jaringan kantor pusat dan cabang secara aman menggunakan protokol modern WireGuard dan konfigurasi Site-to-Site.

10
🟥 LEVEL 10 — LOAD BALANCING & FAILOVER

Gabung 2 ISP (Multi-ISP), PCC (Per Connection Classifier), & Failover Otomatis

Poin Pembelajaran:

Menggabungkan dua jalur internet (ISP 1 & ISP 2) agar beban terbagi merata serta mekanisme failover (jika ISP 1 mati, otomatis pindah ke ISP 2).

11
🟪 LEVEL 11 — MONITORING & TROUBLESHOOTING

CPU, RAM, Torch, Ping, Log, & 6 Pertanyaan Wajib Troubleshooting

Poin Pembelajaran:

Memantau kesehatan router (CPU load, RAM, traffic interface) dan menguasai teknik investigasi masalah jaringan secara sistematis.

  • Kenapa client tidak dapat IP DHCP?
  • Kenapa ping gateway berhasil tapi internet mati?
  • Kenapa NAT tidak berfungsi?
  • Kenapa VLAN antar segment tidak bisa komunikasi?
12
🏆 LEVEL 12 — PROJECT AKHIR JARINGAN SEKOLAH

Implementasi Gabungan: DHCP + DNS + NAT + Firewall + VLAN + Hotspot + VPN

Ringkasan Project Akhir:

Membangun arsitektur jaringan skala sekolah lengkap dari hulu ke hilir:

  • VLAN 10 = ADMIN (Full Access)
  • VLAN 20 = GURU (Controlled Access)
  • VLAN 30 = SISWA (Limited / Hotspot Voucher)
  • VLAN 40 = TAMU
  • Dilengkapi Failover & Multi-ISP Load Balancing.

Deployment

🚀 Panduan Upload ke GitHub Pages

Publiskan website kurikulum MikroTik ini secara gratis di internet dalam 3 langkah mudah.

1

Buat Repository Baru

Login ke akun GitHub kamu, klik tombol New Repository, beri nama misalnya kurikulum-mikrotik, dan atur ke mode Public.

2

Upload file index.html

Upload kode lengkap dari file ini dengan nama file persis index.html ke dalam repository tersebut melalui web GitHub atau Git CLI.

3

Aktifkan GitHub Pages

Buka menu Settings > Pages. Pada bagian Build and deployment, pilih Branch ke main / root, lalu klik Save.

Selesai! Website kamu dapat diakses secara publik di URL:

https://usernamekamu.github.io/kurikulum-mikrotik
